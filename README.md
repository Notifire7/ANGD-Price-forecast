# AMATANGD — Forecast ราคาก๊าซ → Dashboard ส่งลูกค้า

โฟลเดอร์นี้แปลงไฟล์ Excel forecast ของ Marketing (ชีท `Amata-FO` / `Amata-LPG` /
`Amata-COGEN`) เป็นหน้าเว็บให้ลูกค้าเปิดดูราคาของตัวเอง

เป็นฝาแฝดของโปรเจกต์ `NGD-Price-forecast` (PTTNGD) — ใช้ไฟล์ Excel ต้นฉบับไฟล์เดียวกัน
แต่คนละชีท คนละรหัส คนละ repo

## รอบเดือน

1. เอาไฟล์ Excel จาก Marketing วางใน `input/`
2. พิมพ์ใน Cowork ว่า **"รันรอบเดือน"** (หรือรัน `./monthly.sh` เอง)

สคริปต์จะทำตามลำดับ

1. ดึงข้อมูล + ตรวจผังคอลัมน์
2. เทียบกับรอบก่อน แล้ว **หยุดถาม** ว่าจะ build ต่อไหม
3. build ลง `docs/index.html` (ลิงก์เดิม) และ `out/internal_*.html` (ใช้ภายใน)
4. รัน `preflight.py` — ถ้าเจอความลับจะหยุด ไม่ push
5. **หยุดถามอีกรอบ** ว่าจะ push ไหม แล้วค่อย commit + push

ที่ต้องดูให้ดีที่สุดคือผล diff — **เดือนที่เคยแจ้งลูกค้าว่าเป็นราคาจริงแต่ตัวเลขเปลี่ยน**
จะติดป้าย `←` ไว้ให้ พวกนั้นต้องแจ้งลูกค้า ไม่ใช่ปล่อยผ่าน

## หน้าที่ส่งลูกค้า

เป็น **ไฟล์เดียว** `docs/index.html` รวมทั้ง 4 กลุ่ม ลิงก์เดียวแจกได้ทุกกลุ่ม
แต่ละกลุ่มมีรหัสของตัวเอง เปิดได้เฉพาะข้อมูลกลุ่มตัวเอง

ไม่ใช่แค่ซ่อนบนหน้าจอ — ข้อมูลแต่ละกลุ่มเข้ารหัส AES-256-GCM ด้วยกุญแจสุ่ม 256-bit
คนละดอก รหัสผ่านแต่ละชุดถือพวงกุญแจเฉพาะกลุ่มที่มีสิทธิ์ (PBKDF2-SHA256 250,000 รอบ)
คนที่มีรหัสกลุ่มเดียวจะแกะข้อมูลกลุ่มอื่นไม่ได้เลย

## ผังคอลัมน์อยู่ใน `groups.json`

ไม่ได้ฝังในโค้ด ถ้า Marketing ย้ายคอลัมน์ แก้ไฟล์นี้ที่เดียว
ทำแบบนี้เพื่อให้ไฟล์ `.py` ของโฟลเดอร์นี้กับของ PTTNGD เหมือนกันทุกตัวอักษร
แก้บั๊กทีเดียวแล้วก๊อปข้ามโฟลเดอร์ได้

| กลุ่ม | ชีท | Cn | ราคา |
|---|---|---|---|
| Cogen ค่าท่อ (-8) Gas Turbine | Amata-COGEN | O | Q |
| Cogen ค่าท่อ (+3) Gas Engine | Amata-COGEN | U | W |
| AMATA-FO | Amata-FO | G | Block 1–5 ที่ I K M O Q |
| AMATA-LPG | Amata-LPG | H | Block 1–5 ที่ J L N P R |

## เส้นแบ่งราคาจริง / ประมาณการ

คิดเองจากวันที่ในไฟล์ (cell `Amata-FO!B1`) ไม่ต้องแก้โค้ดทุกเดือน

| ชีท | กติกา | ไฟล์ลง 11 ส.ค. 69 |
|---|---|---|
| Amata-COGEN | จริงถึง **เดือนของไฟล์** | จริงถึง ส.ค. |
| Amata-FO, Amata-LPG | จริงถึง **เดือนก่อนหน้า** | จริงถึง ก.ค. |

เพราะ Sn ของ COGEN ใช้ Wellhead เดือน N-1 ที่ประกาศแล้ว ส่วน FO/LPG ยังต้องรอ FX
เฉลี่ยของเดือนปัจจุบันจนสิ้นเดือน

## ห้ามให้ความลับหลุดขึ้น GitHub

`.gitignore` กัน `profiles.json` (รหัสผ่าน), `data.json` + `archive/` (ราคา plaintext),
`input/` (ไฟล์ Excel ต้นฉบับ) และ `out/` (ไฟล์ internal ที่เห็นครบทุกกลุ่ม)

แต่ `.gitignore` พังเงียบ ๆ ได้ เลยมี `preflight.py` ตรวจซ้ำ 4 ชั้นก่อน push

**repo เป็น public** ⇒ ใครก็โหลด `docs/index.html` ไปนั่งเดารหัสแบบ offline ได้ไม่จำกัดเวลา
และไฟล์ของ **ทุกเดือน** ค้างในประวัติ git ถาวร ⇒ รหัสต้องยาวจริง (ใช้สุ่ม 24 ตัว)
ถ้ารหัสเดือนไหนหลุด ข้อมูลเดือนนั้นถือว่าเปิดถาวร เปลี่ยนรหัสทีหลังไม่ช่วยย้อนหลัง

## โครงสร้าง

```
input/       ไฟล์ Excel จาก Marketing (อ่านอย่างเดียว, ไม่ขึ้น git)
docs/        หน้าที่เผยแพร่จริงบน GitHub Pages — ขึ้น git
out/         ไฟล์ internal ใช้ภายใน — ไม่ขึ้น git
archive/     data.json ของรอบก่อน ๆ — ไม่ขึ้น git
data.json    ข้อมูลรอบปัจจุบัน — ไม่ขึ้น git
groups.json  ผังคอลัมน์ — ขึ้น git ได้ ไม่มีความลับ
```
